# ♻️ EcoTech

> Aplicação web para mapeamento de ecopontos e conscientização sobre o descarte adequado de Resíduos de Equipamentos Eletroeletrônicos (REEE).

Projeto desenvolvido como requisito acadêmico para o curso de Ciência da Computação (Universidade Federal da Fronteira Sul - UFFS).

---

## 🎯 Sobre o Projeto

O acelerado avanço tecnológico gera um volume crescente de lixo eletrônico. O **EcoTech** atua na redução da barreira informacional, conectando a intenção de descarte responsável por parte do cidadão à infraestrutura de coleta existente. 

Este projeto está diretamente alinhado à **ODS 12 (Consumo e Produção Responsáveis)** da ONU, atuando na conscientização da população e no fomento à logística reversa de componentes como baterias, monitores e periféricos.

## 🚀 Tecnologias Utilizadas

O projeto está sendo construído com uma stack estática focada em performance e responsividade (*mobile-first*):

* **HTML5:** Estruturação semântica e acessibilidade.
* **CSS3:** Estilização base.
* **Tailwind CSS:** Framework utility-first para desenvolvimento ágil da interface.
